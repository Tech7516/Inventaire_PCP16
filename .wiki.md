# Project Summary
The project is an advanced inventory management application tailored for warehouse operations, enhancing efficiency across various lots such as Lot V, Lot VPS, Lot C, and Lot CAI. Recent updates have improved tracking capabilities, expanded inventory types, and introduced a discrepancy report page for consumables with differing quantities and locations. The application ensures log entries are created only after complete inventory verification, optimizing workflows and reducing clutter. Users can now download summary reports of discrepancies and reset inventory states post-verification. Additionally, it supports variants for Lot C, improving user experience and selection coherence.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots with their last verification date. Users can view the status and location of lots to begin inventory processes. Lot C includes a dropdown for selecting "Lot C Alpha" and "Lot C Bravo."
- **Sub-Entities Page**: Lists all sub-entities for the selected lot, allowing inventory verification. Titles exclude "- Passy" for all lots except Lot A, and lots with variants display the variant name as the title. The page pre-selects sub-entities based on the chosen variant from the home page.
- **Inventory Form Page**: Manages inventory validation for selected sub-entities. All consumables are pre-checked as compliant, with log entries recorded upon full lot verification. Users are redirected to the discrepancy report page upon saving, and the state resets after saving.
- **Log Page**: Displays a history of completed inventories, grouped by lot, without a user icon, showing relevant details for each entry.
- **Discrepancy Report Page**: Lists consumables with differing quantities, including item name, location, actual vs expected quantity, and missing count. Users can download a summary report of discrepancies.
- **Lot CAI**: A new lot added to the home page featuring direct inventory with three sections: Accueil, Consommables, and Administratif.

# File Description Inventory
- **src/App.tsx**: Main application component managing routing, including navigation to sub-entities, log pages, and the discrepancy report page.
- **src/pages/Index.tsx**: Home page component displaying lots and their last verification dates, now including dropdowns for Lot C variants.
- **src/pages/SubEntities.tsx**: Component for displaying sub-entities of a selected lot, updated to ensure pre-selection correctly overwrites localStorage values.
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected lot, resets completed state after saving.
- **src/pages/Log.tsx**: Component displaying the inventory log without a user icon.
- **src/pages/Report.tsx**: Component displaying discrepancies in consumables, including a new download button for summary reports.
- **src/data/lots.ts**: Data structure defining lots and their associated sub-entities, now includes Lot CAI and its consumables, along with updated variants for Lot C.

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
