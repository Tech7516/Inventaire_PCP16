# Project Summary
This project is an advanced inventory management system designed to optimize operational efficiency and enhance user experience for businesses. It offers collaborative features that allow multiple users to conduct inventory checks simultaneously. Key functionalities include user authentication, robust PostgreSQL database management, file storage, and AI integration, providing comprehensive oversight of inventory processes. Recent updates have improved data integrity and user experience by migrating inventory logs from local storage to a shared database, resolving issues related to blank pages and enhancing application performance. The system now also includes a centralized reporting feature for discrepancy reports, further streamlining inventory management.

# Project Module Description
The project consists of various functional modules, including:
- **Authentication:** User registration, login, and session management.
- **Database Management:** PostgreSQL integration for CRUD operations and table management.
- **File Storage:** Object storage for managing images, videos, and documents.
- **Edge Functions:** Custom server-side APIs built with FastAPI.
- **AI Capabilities:** Features for text, image, and audio generation, along with PDF analysis and voice transcription.
- **Collaborative Inventory Management:** Facilitates multiple users in managing inventory checks on the same lot, including session creation, validation, and abandonment.
- **Discrepancy Reporting:** Stores and manages reports of discrepancies in inventory, ensuring that only the latest report is retained for each lot and variant.

# Usage
1. **Install Dependencies:**
   - For backend: Run `pip install -r app/backend/requirements.txt`
   - For frontend: Run `pnpm install` in the `app/frontend/` directory.
   
2. **Build the Project:**
   - For the frontend: Run `pnpm run build` in the `app/frontend/` directory.

3. **Run the Application:**
   - Start the backend server using `uvicorn app.backend.main:app --reload`
   - Start the frontend development server using `pnpm start` in the `app/frontend/` directory.
