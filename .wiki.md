# Project Summary
The project is an advanced inventory management application designed specifically for warehouse operations. It provides an intuitive interface that simplifies the management of inventory across multiple lots, including the recently integrated Lot V, Lot VPS, and Lot C. Recent updates have enhanced tracking capabilities, expanded the range of inventory types, and introduced a discrepancy report page that lists consumables with differing quantities and their exact locations, improving user experience and operational efficiency. The application ensures that log entries are created only upon complete inventory verification, streamlining the process and reducing clutter.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots, including Lot V, Lot VPS, and Lot C, with dropdown menus for selecting variants (VL Poussin, VPS Auteuil, VPS Neuilly). Users can view the status and location of lots to initiate inventory processes.
- **Sub-Entities Page**: Lists all sub-entities associated with a selected lot, allowing users to select Lot variants and perform inventory verification. Log entries are created only when the "Sauvegarder/Envoyer" button is clicked, which now also redirects users to the discrepancy report page.
- **Inventory Form Page**: Facilitates inventory validation for selected sub-entities. All consumables are pre-checked as compliant by default, allowing users to uncheck and specify quantities as necessary. Log entries are recorded only upon full lot verification, and users are redirected to the discrepancy report page upon saving.
- **Log Page**: Displays a history of completed inventories, grouped by lot. Each entry includes the sub-entity name, verified variant, sac type (soin/O2), DPS name, and timestamp. The user icon has been removed, and the DPS name is now displayed as plain text.
- **Discrepancy Report Page**: Lists all consumables with differing quantities, showing item name, location, actual vs expected quantity, and missing count.

# File Description Inventory
- **src/App.tsx**: Main application component that sets up routing, including navigation to the sub-entities and log pages, as well as the new discrepancy report page.
- **src/pages/Index.tsx**: Home page component displaying lots, including Lot V, Lot VPS, and Lot C, with updated information and links to their respective inventories.
- **src/pages/SubEntities.tsx**: Component for displaying sub-entities of a selected lot, now redirects to the discrepancy report page on "Sauvegarder/Envoyer".
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected lot, pre-checks all consumables as compliant, and redirects to the discrepancy report page upon saving.
- **src/pages/Log.tsx**: Updated component that displays the inventory log, showing relevant details for each completed inventory without a user icon.
- **src/pages/Report.tsx**: New component that displays discrepancies in consumables, including item names, locations, and quantity differences.
- **src/data/lots.ts**: Data structure defining lots, their associated sub-entities, and consumable sections, reflecting recent updates including the addition of Lot C and its inventory items.

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
