# Project Summary
Application web de gestion d’inventaire collaborative, structurée en lots/sous-lots configurés en admin, et pilotant des sessions de contrôle historisées dans PostgreSQL. Les données sont synchronisées entre mobile et desktop via un journal d’événements et des préférences cloud.

# Project Module Description
- Admin lots/sous-lots (config) : création/édition des configurations utilisées pour générer les sessions.
- Sessions & collaboration : création et navigation dans les sous-ensembles à contrôler.
- Checks des sous-entités : enregistrement des contrôles par session, dont le type d’intervention (DPS vs Désinfection).
- Inventaire (items) : persistance et affichage des items issus des configurations et des contrôles.
- Journal & événements : historisation des actions et traçage du type d’intervention.
- Rapports de divergences : calcul des écarts et génération à partir du journal.
- Édition de rapports (frontend) : édition depuis le journal puis sauvegarde en base.
- API backend & données : FastAPI + SQLAlchemy async + PostgreSQL, migrations Alembic ; endpoints partagés pour contourner le filtrage RLS sur les données communes.
- Frontend : React/TypeScript ; synchronisation via endpoints backend partagés (journal/rapports/préférences/configs) pour cohérence inter-appareils.

# Directory Tree
app/
- backend/ : API FastAPI (routers, services, modèles/schemas, migrations)
- backend/alembic/versions/ : historique des migrations
- backend/data_models/ : modèles JSON (configs, items, logs, sessions, checks, rapports, préférences)
- backend/models/ : modèles SQLAlchemy (persistance des entités métier)
- backend/routers/ : endpoints CRUD et consultation par entité
- backend/routers/shared_data.py : routes partagées /api/v1/shared sans filtrage RLS (logs/rapports/préférences/configs)
- backend/services/ : logique métier (configs, sessions/items/logs/checks/rapports, préférences)
- frontend/ : application React/TypeScript
- uploads/ : fichiers téléversés
- scripts/ : scripts de démarrage/packaging

# Technology Stack
- Backend : FastAPI, PostgreSQL, SQLAlchemy (async), Alembic
- Frontend : React, TypeScript, Tailwind CSS
- Déploiement : Atoms Cloud

# Usage
1. Backend : `pip install -r app/backend/requirements.txt`
2. Frontend : `pnpm install` dans `app/frontend/`
3. Build frontend : `pnpm run build` dans `app/frontend/`
