# Project Summary
This project is an advanced inventory management system designed to enhance operational efficiency and improve user experience for businesses. It enables collaborative features, allowing multiple users to conduct inventory checks simultaneously. Key functionalities include user authentication, robust PostgreSQL database management, and AI integration for comprehensive oversight of inventory processes. Recent updates have focused on improving data integrity, user experience, and centralized reporting for discrepancies, further streamlining inventory management. New improvements include enhanced error handling and user-friendly messaging for 404 errors.

# Project Module Description
The project consists of various functional modules, including:
- **Authentication:** User registration, login, and session management.
- **Database Management:** PostgreSQL integration for CRUD operations and table management.
- **File Storage:** Object storage for managing images, videos, and documents.
- **Edge Functions:** Custom server-side APIs built with FastAPI.
- **AI Capabilities:** Features for text, image, and audio generation, along with PDF analysis and voice transcription.
- **Collaborative Inventory Management:** Facilitates multiple users in managing inventory checks on the same lot, including session creation, validation, and abandonment.
- **Discrepancy Reporting:** Manages reports of discrepancies in inventory, ensuring the latest report is retained for each lot and variant, now including detailed reporting with lot variant names and DPS (Data Processing System) names.
- **Error Handling:** New error boundaries and a catch-all route for improved user experience during errors.

# Usage
1. **Install Dependencies:**
   - For backend: Run `pip install -r app/backend/requirements.txt`
   - For frontend: Run `pnpm install` in the `app/frontend/` directory.
   
2. **Build the Project:**
   - For the frontend: Run `pnpm run build` in the `app/frontend/` directory.

3. **Run the Application:**
   - Start the backend server using `uvicorn app.backend.main:app --reload`
   - Start the frontend development server using `pnpm start` in the `app/frontend/` directory.
