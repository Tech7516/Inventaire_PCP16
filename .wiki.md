# Project Summary
The project is an advanced inventory management application tailored for warehouse operations, streamlining inventory management across multiple lots, including Lot V, Lot VPS, and Lot C. Recent enhancements have improved tracking capabilities, expanded inventory types, and introduced a discrepancy report page detailing consumables with differing quantities and locations. The application ensures log entries are created only after complete inventory verification, thus optimizing workflow and reducing clutter. New features now allow users to download summary reports of discrepancies and reset inventory states post-verification.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots with options for selecting variants. Users can view the status and location of lots to begin inventory processes.
- **Sub-Entities Page**: Lists all sub-entities for the selected lot, allowing inventory verification. Log entries are created upon clicking "Sauvegarder/Envoyer", which redirects to the discrepancy report page.
- **Inventory Form Page**: Manages inventory validation for selected sub-entities. All consumables are pre-checked as compliant, with log entries recorded upon full lot verification. Users are redirected to the discrepancy report page upon saving, and the state resets after saving.
- **Log Page**: Displays a history of completed inventories, grouped by lot, without a user icon, showing relevant details for each entry.
- **Discrepancy Report Page**: Lists consumables with differing quantities, including item name, location, actual vs expected quantity, and missing count. Users can now download a summary report of discrepancies.

# File Description Inventory
- **src/App.tsx**: Main application component managing routing, including navigation to sub-entities and log pages, as well as the discrepancy report page.
- **src/pages/Index.tsx**: Home page component displaying lots and links to their respective inventories.
- **src/pages/SubEntities.tsx**: Component for displaying sub-entities of a selected lot, now resets the inventory state and DPS name after saving.
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected lot, resets completed state after saving.
- **src/pages/Log.tsx**: Component displaying the inventory log without a user icon.
- **src/pages/Report.tsx**: Component displaying discrepancies in consumables, including a new download button for summary reports.
- **src/data/lots.ts**: Data structure defining lots and their associated sub-entities.

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
