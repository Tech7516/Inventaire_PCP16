# Project Summary
The project is an advanced inventory management application specifically designed for warehouse operations. It provides an intuitive interface that enables users to efficiently manage inventory across multiple lots, including the newly integrated Lot V and Lot VPS. Recent updates have enhanced tracking capabilities and expanded inventory types, significantly improving user experience and operational efficiency.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots, including Lot V and Lot VPS, with dropdown menus for selecting variants (VL Poussin, VTP Passy, VPS Auteuil, VPS Neuilly). Users can view the status and location of lots to initiate inventory processes.
- **Sub-Entities Page**: Lists all sub-entities associated with a selected lot, allowing users to select Lot variants and perform inventory verification.
- **Inventory Form Page**: Facilitates inventory validation for selected sub-entities, including sections for grouping consumables by location within the lot and marking inventories as completed upon submission.

# File Description Inventory
- **src/App.tsx**: Main application component that sets up routing, including navigation to the sub-entities page.
- **src/pages/Index.tsx**: Home page component displaying lots, including the newly added Lot V and Lot VPS, with updated information and links to their respective inventories.
- **src/pages/SubEntities.tsx**: Component for displaying sub-entities of a selected lot, now includes dropdowns for selecting Lot variants and buttons for inventory verification.
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected lot, including sections for grouping consumables by location and marking inventories as completed upon submission.
- **src/data/lots.ts**: Data structure defining lots, their associated sub-entities, and consumable sections, reflecting recent updates including the addition of Lot V and its inventory items.

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
