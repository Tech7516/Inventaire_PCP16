# Project Summary
This project is an advanced inventory management system aimed at enhancing operational efficiency and user experience for businesses. It supports collaborative features, allowing multiple users to perform inventory checks simultaneously. Key functionalities include user authentication, robust PostgreSQL database management, and AI integration, which provide comprehensive oversight of inventory processes. Recent updates have focused on improving data integrity and user experience by migrating inventory logs to a shared database, resolving blank page issues, and enhancing application performance. The system now features a centralized reporting tool for discrepancy reports, streamlining inventory management further.

# Project Module Description
The project consists of various functional modules, including:
- **Authentication:** User registration, login, and session management.
- **Database Management:** PostgreSQL integration for CRUD operations and table management.
- **File Storage:** Object storage for managing images, videos, and documents.
- **Edge Functions:** Custom server-side APIs built with FastAPI.
- **AI Capabilities:** Features for text, image, and audio generation, along with PDF analysis and voice transcription.
- **Collaborative Inventory Management:** Facilitates multiple users in managing inventory checks on the same lot, including session creation, validation, and abandonment.
- **Discrepancy Reporting:** Manages reports of discrepancies in inventory, ensuring the latest report is retained for each lot and variant. Recent updates include detailed reporting that now displays the lot variant name and the DPS (Data Processing System) name.

# Usage
1. **Install Dependencies:**
   - For backend: Run `pip install -r app/backend/requirements.txt`
   - For frontend: Run `pnpm install` in the `app/frontend/` directory.
   
2. **Build the Project:**
   - For the frontend: Run `pnpm run build` in the `app/frontend/` directory.

3. **Run the Application:**
   - Start the backend server using `uvicorn app.backend.main:app --reload`
   - Start the frontend development server using `pnpm start` in the `app/frontend/` directory.
