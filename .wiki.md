# Project Summary
The project is an advanced inventory management application tailored for warehouse operations, focusing on enhancing inventory management and execution across various lots. It aims to improve usability and organization through an intuitive interface that allows users to select lots and input inventory details for precise stock tracking. Recent enhancements include a new field for the DPS name, persistent selection for Lot B, and a save/send button, all aimed at improving user experience and functionality.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots with their status and location, allowing users to initiate inventory processes.
- **Sub-Entities Page**: Lists all sub-entities associated with a selected lot, featuring a dropdown for selecting Lot B variants, updated buttons for inventory verification, and a detailed inventory structure for care and O2 bags, along with a new DPS name field.
- **Inventory Form Page**: Facilitates inventory validation for selected sub-entities, including sections for grouping consumables by location within the lot and marking inventories as completed upon submission.

# File Description Inventory
- **src/App.tsx**: Main application component that sets up routing, including navigation to the sub-entities page.
- **src/pages/Index.tsx**: Home page component displaying lots with updated information and links to their respective sub-entities.
- **src/pages/SubEntities.tsx**: Updated component for displaying sub-entities of a selected lot, now includes a dropdown for selecting Lot B variants, new buttons for inventory verification, and a field for the DPS name.
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected sub-entity, including sections for grouping consumables by location and marking inventories as completed upon submission.
- **src/data/lots.ts**: Data structure defining lots, their associated sub-entities, and consumable sections, reflecting recent updates in organization and variant support.

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
