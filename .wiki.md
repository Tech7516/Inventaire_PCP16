# Project Summary
Application web de gestion d’inventaire collaborative orchestrant des sessions de contrôle par lots entre utilisateurs, initialisées depuis une configuration admin et historisées en PostgreSQL (authentification, sessions, contrôles, logs et divergences). Le produit propose une interface orientée mobile et des rapports de divergences téléchargeables, consultables depuis un journal d’événements lié aux sessions.

# Project Module Description
- Configuration lots/sous-lots (Admin + persistance) : création/édition de la structure (lots/sous-lots/sections) côté backend, chargée ensuite par le front.
- Inventaire & collaboration : génération d’une session d’inventaire depuis les configurations et présentation des sous-ensembles à contrôler.
- Contrôles de sous-entités : enregistrement des checks par sous-ensemble, associés à la session.
- Inventaire (items) : persistance et affichage des items issus des configurations.
- Log & événements : journal des actions/événements de session, regroupés par sections, et accès aux rapports de divergences.
- Rapports de divergences : calcul et restitution des divergences par lot/variant via API, avec fichiers téléchargeables.
- Backend API & données : FastAPI + SQLAlchemy async + PostgreSQL, migrations via Alembic.
- Frontend : React/TypeScript avec store de configuration côté front.

# Directory Tree
app/
- backend/ : API FastAPI (routers, services, modèles/schemas, migrations)
- backend/alembic/versions/ : historique des migrations
- backend/data_models/ : fichiers JSON de modèles/références (config, items, logs, sessions, checks, rapports)
- backend/models/ : modèles SQLAlchemy pour la persistance (config, items, logs, sessions, checks, rapports)
- backend/routers/ : endpoints CRUD et consultation par entité
- backend/services/ : logique métier (chargement/sauvegarde configs, opérations sessions/items/logs/checks/rapports)
- frontend/ : application React/TypeScript
- frontend/src/lib/ : store et helpers côté front (configurations)
- frontend/src/pages/ : pages (Index, Inventory, SubEntities, Admin, Log, etc.)
- uploads/ : stockage local de fichiers téléversés
- scripts/ : scripts de démarrage/packaging

# File Description Inventory
- app/frontend/src/pages/Log.tsx : page du journal; regroupe et affiche les entrées par sections, et présente les rapports de divergences téléchargeables (dont Lot B et Lot C).

# Technology Stack
- Backend : FastAPI, PostgreSQL, SQLAlchemy (async), Alembic
- Frontend : React, TypeScript, Tailwind CSS
- Déploiement : Atoms Cloud

# Usage
1. Backend : `pip install -r app/backend/requirements.txt`
2. Frontend : `pnpm install` dans `app/frontend/`
3. Build frontend : `pnpm run build` dans `app/frontend/`
