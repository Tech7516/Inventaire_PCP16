# Project Summary
The project is an inventory management application tailored for warehouses, allowing users to efficiently manage and conduct inventories of various lots. It features a streamlined interface for selecting lots and inputting inventory details, enhancing the inventory process and ensuring accurate tracking of stock levels. The application has been updated to include a comprehensive list of consumables, improving usability and organization.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots with their status and location. Users can initiate an inventory from here.
- **Inventory Form Page**: Facilitates inventory validation. Consumables are organized into sections by location within the lot for better clarity and usability.

# File Description Inventory
- **src/App.tsx**: Main application component that sets up routing.
- **src/pages/Index.tsx**: Home page component displaying lots with updated information.
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected lot, now includes sections for grouping consumables by location.
- **src/data/lots.ts**: Data structure defining lots and their associated consumable sections, reflecting recent updates in consumable organization.
- **src/components/ui/**: Contains reusable UI components like buttons, cards, and inputs.

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
