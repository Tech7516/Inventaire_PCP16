# Project Summary
The project is an advanced inventory management application designed specifically for warehouses. It enables users to efficiently manage and conduct inventories of various lots, with a focus on improving usability and organization. The application features an intuitive interface for selecting lots and inputting inventory details, ensuring accurate tracking of stock levels. Recent updates have introduced a detailed page for sub-entities within lots, enhancing the user experience by allowing users to verify consumables associated with each sub-entity.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots with their status and location. Users can initiate an inventory from here.
- **Sub-Entities Page**: An intermediary page that lists all sub-entities associated with a selected lot, allowing users to navigate to specific consumables for verification.
- **Inventory Form Page**: Facilitates inventory validation for selected sub-entities. Consumables are organized into sections by location within the lot for better clarity and usability.

# File Description Inventory
- **src/App.tsx**: Main application component that sets up routing, including navigation to the new sub-entities page.
- **src/pages/Index.tsx**: Home page component displaying lots with updated information and links to their respective sub-entities.
- **src/pages/SubEntities.tsx**: New component for displaying sub-entities of a selected lot, allowing navigation to inventory forms for each sub-entity.
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected sub-entity, including sections for grouping consumables by location.
- **src/data/lots.ts**: Data structure defining lots, their associated sub-entities, and consumable sections, reflecting recent updates in organization.

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
