# Project Summary
The project is an advanced inventory management application tailored for warehouse operations. It features an intuitive interface designed to streamline the management of inventory across multiple lots, including the recently integrated Lot V and Lot VPS. The latest updates have improved tracking capabilities, expanded inventory types, and introduced a log page to enhance user experience and operational efficiency.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots, including Lot V and Lot VPS, with dropdown menus for selecting variants (VL Poussin, VPS Auteuil, VPS Neuilly). Users can view the status and location of lots to initiate inventory processes.
- **Sub-Entities Page**: Lists all sub-entities associated with a selected lot, allowing users to select Lot variants and perform inventory verification.
- **Inventory Form Page**: Facilitates inventory validation for selected sub-entities, including sections for grouping consumables by location within the lot and marking inventories as completed upon submission.
- **Log Page**: Displays a history of completed inventories, grouped by lot. Each entry includes the sub-entity name, verified variant, sac type (soin/O2), DPS name, and timestamp. Users can clear the log entries.

# File Description Inventory
- **src/App.tsx**: Main application component that sets up routing, including navigation to the sub-entities and log pages.
- **src/pages/Index.tsx**: Home page component displaying lots, including the newly added Lot V and Lot VPS, with updated information and links to their respective inventories.
- **src/pages/SubEntities.tsx**: Component for displaying sub-entities of a selected lot, now includes dropdowns for selecting Lot variants and buttons for inventory verification.
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected lot, including sections for grouping consumables by location and marking inventories as completed upon submission. Now logs completions with timestamp and DPS name.
- **src/pages/Log.tsx**: New component that displays the inventory log with entries grouped by lot, showing relevant details for each completed inventory.
- **src/data/lots.ts**: Data structure defining lots, their associated sub-entities, and consumable sections, reflecting recent updates including the addition of Lot V and its inventory items.

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
