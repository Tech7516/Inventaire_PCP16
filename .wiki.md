# Project Summary
The project is an inventory management application designed for warehouses, enabling users to manage and conduct inventories of various lots. It features a user-friendly interface where users can select lots and input inventory details, making the process efficient and organized.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots with their status, location, and expected item count. Users can start an inventory from here.
- **Inventory Form Page**: Allows users to input details about items in the selected lot, including name, quantity, condition, and comments.

# File Description Inventory
- **src/App.tsx**: Main application component that sets up routing.
- **src/pages/Index.tsx**: Home page component displaying lots.
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected lot.
- **src/data/lots.ts**: Data structure defining lots available for inventory.
- **src/components/ui/**: Contains reusable UI components like buttons, cards, and inputs.

# Technology Stack
- React for building user interfaces
- TypeScript for type safety
- Tailwind CSS for styling
- Vite for development and build tooling
- ESLint for code quality
- Sonner for toast notifications

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
