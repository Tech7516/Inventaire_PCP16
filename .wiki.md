# Project Summary
Application web de gestion d’inventaire collaborative : elle orchestre des sessions de contrôle par lots entre utilisateurs, en initialisant l’inventaire depuis une configuration admin et en stockant l’activité (authentification, sessions, contrôles, logs et divergences) en PostgreSQL. Le produit fournit une interface front orientée mobile et des rapports de divergences consultables, avec un journal d’événements lié aux sessions.

# Project Module Description
- Configuration lots/sous-lots (Admin + persistance) : interface admin pour créer/éditer la structure (lots/sous-lots/sections) stockée côté backend, puis chargée côté front pour construire l’inventaire.
- Inventaire & collaboration : génération d’une session d’inventaire à partir des configurations et affichage des sous-ensembles à contrôler.
- Contrôles de sous-entités : enregistrement des checks par sous-ensemble, associés à la session.
- Inventaire (items) : persistance et affichage des items via les configurations.
- Log & événements : journal consultable des actions/événements de session, avec regroupements par sections.
- Rapports de divergences : création/calcul et restitution des divergences par lot/variant via API.
- Backend API & données : FastAPI + SQLAlchemy async + PostgreSQL, avec migrations via Alembic.
- Frontend : React/TypeScript, chargement de configurations via un store côté front.

# Directory Tree
app/
- backend/ : API FastAPI (modèles/schemas, routers, services, migrations)
- backend/alembic/versions/ : historique des migrations
- backend/data_models/ : JSON de modèles/références (config, items, logs, sessions, checks, rapports)
- backend/models/ : modèles SQLAlchemy de persistance (config, items, logs, sessions, checks, rapports)
- backend/routers/ : endpoints CRUD et consultation par entité
- backend/services/ : logique métier (chargement/sauvegarde configs, opérations sessions/items/logs/checks/rapports)
- frontend/ : application React/TypeScript
- frontend/src/lib/ : store de configuration côté front
- frontend/src/pages/ : pages (Index, Inventory, SubEntities, Admin, Log, etc.)
- uploads/ : stockage local des fichiers téléversés
- scripts/ : scripts de démarrage/packaging

# File Description Inventory
- app/frontend/src/pages/Log.tsx : page du journal; regroupement/affichage des entrées par sections de lots, et affichage des contrôles d’accès aux rapports (notamment pour Lot B).

# Technology Stack
- Backend : FastAPI, PostgreSQL, SQLAlchemy (async), Alembic
- Frontend : React, TypeScript, Tailwind CSS
- Déploiement : Atoms Cloud

# Usage
1. Backend : `pip install -r app/backend/requirements.txt`
2. Frontend : `pnpm install` dans `app/frontend/`
3. Build frontend : `pnpm run build` dans `app/frontend/`
