# Project Summary
The project is an advanced inventory management application designed specifically for warehouse operations. It enhances usability and organization through an intuitive interface, allowing users to effectively manage inventory across various lots. Recent updates include improved tracking features and the introduction of new inventory types for different lots, enhancing overall functionality and user experience.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots, including Lot C, with their status and location, enabling users to initiate inventory processes.
- **Sub-Entities Page**: Lists all sub-entities associated with a selected lot, featuring dropdowns for selecting Lot B variants and new options for POM and caisse, along with updated buttons for inventory verification.
- **Inventory Form Page**: Facilitates inventory validation for selected sub-entities, including sections for grouping consumables by location within the lot and marking inventories as completed upon submission.

# File Description Inventory
- **src/App.tsx**: Main application component that sets up routing, including navigation to the sub-entities page.
- **src/pages/Index.tsx**: Home page component displaying lots with updated information and links to their respective sub-entities.
- **src/pages/SubEntities.tsx**: Updated component for displaying sub-entities of a selected lot, now includes dropdowns for selecting Lot C variants and buttons for inventory verification.
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected sub-entity, including sections for grouping consumables by location and marking inventories as completed upon submission.
- **src/data/lots.ts**: Data structure defining lots, their associated sub-entities, and consumable sections, reflecting recent updates including a complete replacement of Lot C's consumable list.

# Technology Stack
- React for building user interfaces

- Tailwind CSS for styling
- Vite for development and build tooling
- ESLint for code quality
- Sonner for toast notifications

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
