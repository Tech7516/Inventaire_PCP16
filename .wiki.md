# Project Summary
Application web de gestion d’inventaire orientée collaboration : elle orchestre des sessions de contrôle par lots entre utilisateurs, avec authentification et persistance PostgreSQL. Le produit démarre un nouvel inventaire à partir d’une configuration admin (lots/sous-lots/sections) et fournit des rapports de divergences, des logs consultables, et une UI optimisée mobile.

# Project Module Description
- Configuration lots/sous-lots (Admin + persistance) : interface d’admin pour créer/éditer la structure, stockée côté backend puis chargée côté front pour générer l’inventaire.
- Inventaire & collaboration : création d’une session d’inventaire à partir des configurations et affichage des sous-ensembles à contrôler.
- Contrôles de sous-entités : vérification et enregistrement des checks par sous-ensemble, liés à la session.
- Inventaire (items) : persistance des items d’inventaire et affichage dans l’UI à partir des configs.
- Log & événements : journalisation et consultation des événements liés aux sessions et contrôles.
- Rapports de divergences : calcul/stockage des divergences par lot/variant et restitution via API.
- Backend API & données : FastAPI + SQLAlchemy async + PostgreSQL, avec migrations via Alembic.
- Frontend : React/TypeScript, chargement dynamique des configurations via un store.

- uploads/ : stockage local des fichiers téléversés
- scripts/ : scripts de démarrage/packaging

# Technology Stack
- Backend : FastAPI, PostgreSQL, SQLAlchemy (async), Alembic
- Frontend : React, TypeScript, Tailwind CSS
- Déploiement : Atoms Cloud

# Usage
1. Backend : `pip install -r app/backend/requirements.txt`
2. Frontend : `pnpm install` dans `app/frontend/`
3. Build frontend : `pnpm run build` dans `app/frontend/`
