# Project Summary
Application web de gestion d’inventaire collaborative : l’admin configure des lots/sous-lots, puis les équipes réalisent des sessions historisées de vérifications et de désinfections. Les actions sont synchronisées entre mobile et desktop via un journal d’événements stocké en PostgreSQL, complété par des préférences cloud.

# Project Module Description
- Admin lots/sous-lots (config) : création/édition des configurations utilisées pour générer les sessions.
- Sessions & collaboration : création et navigation dans les sous-ensembles à contrôler.
- Checks des sous-entités : enregistrement des contrôles par session, incluant le type d’intervention (DPS vs désinfection).
- Inventaire (items) : persistance et affichage des items dérivés des configurations et contrôles.
- Journal & événements : historisation des actions pour audit et traçabilité (inclut désinfections).
- Rapports de divergences : calcul des écarts à partir du journal, et génération des rapports.
- Édition de rapports (frontend) : édition depuis le journal puis sauvegarde en base.
- API backend & données : FastAPI + SQLAlchemy async + PostgreSQL, migrations Alembic ; routes partagées pour contourner le filtrage RLS sur les données communes.
- Frontend : React/TypeScript ; cohérence inter-appareils via endpoints backend partagés (journal/rapports/préférences/configs).

app/

- backend/alembic/versions/ : historique des migrations Alembic
- backend/data_models/ : modèles JSON (configs, items, logs, sessions, checks, rapports, préférences)
- backend/models/ : modèles SQLAlchemy (persistance métier)
- backend/routers/ : endpoints CRUD et consultation par entité
- backend/routers/shared_data.py : routes /api/v1/shared sans filtrage RLS (logs/rapports/préférences/configs)
- backend/services/ : logique métier (configs, sessions/items/logs/checks/rapports, préférences)
- frontend/ : application React/TypeScript
- uploads/ : fichiers téléversés
- scripts/ : scripts de démarrage/packaging

# Technology Stack
- Backend : FastAPI, PostgreSQL, SQLAlchemy (async), Alembic
- Frontend : React, TypeScript, Tailwind CSS
- Déploiement : Atoms Cloud

# Usage
1. Backend : `pip install -r app/backend/requirements.txt`
2. Frontend : `pnpm install` dans `app/frontend/`
3. Build frontend : `pnpm run build` dans `app/frontend/`
