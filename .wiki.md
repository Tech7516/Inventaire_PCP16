# Project Summary
Application web de gestion d’inventaire collaborative : création depuis une configuration admin de sessions de contrôle par lots, historisées en base PostgreSQL, avec une interface mobile et des rapports de divergences téléchargeables accessibles depuis le journal.

# Project Module Description
- Configuration lots/sous-lots (Admin) : création/édition côté backend, chargée ensuite par le front.
- Inventaire & collaboration : génération de sessions à partir des configurations et présentation des sous-ensembles à contrôler.
- Contrôles des sous-entités : enregistrement des checks associés à la session.
- Inventaire (items) : persistance et affichage des items dérivés des configurations.
- Log & événements : journal des actions et événements de session, regroupé pour consultation.
- Rapports de divergences : calcul/restitution des divergences et génération de fichiers téléchargeables.
- Backend API & données : FastAPI + SQLAlchemy async + PostgreSQL, migrations via Alembic.
- Frontend : React/TypeScript, logique front et store de configuration.

# Directory Tree
app/
- backend/ : API FastAPI (routers, services, modèles/schemas, migrations)
- backend/alembic/versions/ : historique des migrations
- backend/data_models/ : fichiers JSON de modèles/références (config, items, logs, sessions, checks, rapports)
- backend/models/ : modèles SQLAlchemy pour la persistance (config, items, logs, sessions, checks, rapports)
- backend/routers/ : endpoints CRUD et consultation par entité
- backend/services/ : logique métier (chargement/sauvegarde configs, opérations sessions/items/logs/checks/rapports)
- frontend/ : application React/TypeScript
- frontend/src/lib/ : store et helpers côté front (notamment appels API inventaire)
- frontend/src/pages/ : pages (Index, Inventory, SubEntities, Admin, Log, etc.)
- uploads/ : stockage local de fichiers téléversés
- scripts/ : scripts de démarrage/packaging

# File Description Inventory
- app/frontend/src/pages/Log.tsx : page du journal; affiche les entrées par sections et les boutons/accès aux rapports de divergences.
- app/frontend/src/lib/inventory-api.ts : client côté front pour appeler l’API inventaire, dont les opérations de suppression/effacement.

# Technology Stack
- Backend : FastAPI, PostgreSQL, SQLAlchemy (async), Alembic
- Frontend : React, TypeScript, Tailwind CSS
- Déploiement : Atoms Cloud

# Usage
1. Backend : `pip install -r app/backend/requirements.txt`
2. Frontend : `pnpm install` dans `app/frontend/`
3. Build frontend : `pnpm run build` dans `app/frontend/`
