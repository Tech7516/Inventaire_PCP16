# Project Summary
Application web de gestion d’inventaire orientée collaboration, permettant des contrôles par lot entre utilisateurs avec authentification et persistance PostgreSQL. Le produit propose des rapports de divergences, réduit les erreurs via une navigation UI robuste et intègre un affichage optimisé pour l’usage mobile, incluant la consultation des journaux et états d’exécution.

# Project Module Description
- **Gestion d’authentification** : inscription, connexion, gestion de session.
- **Inventaire & collaboration** : création/validation/abandon de sessions de contrôle par lot, coordination multi-utilisateurs.
- **Rapports de divergences** : conservation du dernier état par lot/variant, affichage enrichi (noms lot/variant) et indicateurs associés.
- **Gestion des erreurs** : limites côté UI + route catch-all pour éviter les écrans cassés.
- **Logs** : regroupement et priorisation des entrées (incluant Lot B) et catégorisation (ex. Cellule).
- **Stockage de fichiers** : gestion des assets (images/vidéos/documents) via stockage côté app.
- **Backend API (FastAPI) & données** : services backend, modèles/schemas, accès PostgreSQL via SQLAlchemy async.
- **IA (selon capacité)** : génération/ analyse (texte/image/audio, PDF/transcription).

# Directory Tree
app/
- **backend/** : API FastAPI (main, routers, services, modèles, schemas, handlers)
- **frontend/** : application React/TypeScript (pages, composants, libs d’accès API)
- **uploads/** : stockage local des fichiers téléversés
- **(scripts)** : scripts de démarrage/packaging côté app

# File Description Inventory
- **app/backend/main.py** : point d’entrée backend, chargement exécuté au démarrage
- **app/backend/requirements.default** : dépendances backend (par défaut)
- **app/backend/requirements.txt** : dépendances backend verrouillées
- **app/start_app_v2.sh** : script de lancement de l’environnement
- **app/frontend/src/pages/Inventory.tsx** : optimisation UI “Inventaire” (mise en page adaptée mobile)

# Technology Stack
- **Backend** : FastAPI, PostgreSQL, SQLAlchemy (async), asyncpg
- **Frontend** : React, TypeScript, Tailwind CSS
- **Déploiement** : Atoms Cloud

# Usage
1. Backend : installer `pip install -r app/backend/requirements.txt`
2. Frontend : installer `pnpm install` dans `app/frontend/`
3. Construire le frontend : `pnpm run build` dans `app/frontend/`
4. Lancer l’application :
   - Backend : `uvicorn app.backend.main:app --reload`
   - Frontend : `pnpm start` dans `app/frontend/`
