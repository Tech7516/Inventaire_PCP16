# Project Summary
This project is a comprehensive inventory management system that utilizes cloud technology to enhance user experience and operational efficiency. It enables businesses to manage their inventories seamlessly through collaborative features, allowing multiple users to conduct inventory checks on the same lot concurrently. The system supports user authentication, database management, file storage, and AI capabilities, providing a robust backend infrastructure for effective inventory oversight.

# Project Module Description
The project consists of various functional modules, including:
- **Authentication:** User registration, login, and session management.
- **Database Management:** PostgreSQL integration for CRUD operations and table management.
- **File Storage:** Object storage for handling images, videos, and documents.
- **Edge Functions:** Custom server-side APIs built with FastAPI.
- **AI Capabilities:** Features for text, image, and audio generation, along with PDF analysis and voice transcription.
- **Collaborative Inventory Management:** Allows multiple users to manage inventory checks on the same lot, with features for session creation, validation, and abandonment.

# File Description Inventory
- **backend/**: Contains all backend-related files, including configuration, models, routers, and services.
- **frontend/**: Contains the frontend application code, including components, pages, assets, and dependency lock files.
- **uploads/**: Stores uploaded documents and files.

# Technology Stack
- **Backend:** FastAPI, PostgreSQL
- **Frontend:** React, TypeScript
- **Deployment:** Atoms Cloud
- **Styling:** Tailwind CSS

# Usage
1. **Install Dependencies:**
   - For backend: Run `pip install -r app/backend/requirements.txt`
   - For frontend: Run `pnpm install` in the `app/frontend/` directory.
   
2. **Build the Project:**
   - For the frontend: Run `pnpm run build` in the `app/frontend/` directory.

3. **Run the Application:**
   - Start the backend server using `uvicorn app.backend.main:app --reload`
   - Start the frontend development server using `pnpm start` in the `app/frontend/` directory.
