# Project Summary
The project is an advanced inventory management application tailored for warehouse operations. It streamlines the management and execution of inventories across various lots, improving usability and organization. The application features an intuitive interface for selecting lots and inputting inventory details, ensuring precise tracking of stock levels. Recent updates have enhanced the user experience, notably by standardizing the button colors for Lot B and incorporating a detailed inventory structure for both the care bag and the O2 bag.

# Project Module Description
The application consists of the following functional modules:
- **Home Page**: Displays available lots with their status and location, enabling users to initiate inventory processes.
- **Sub-Entities Page**: Lists all sub-entities associated with a selected lot, featuring a dropdown for selecting Lot B variants, updated buttons for inventory verification, and now includes the detailed inventory structure for the care and O2 bags.
- **Inventory Form Page**: Facilitates inventory validation for selected sub-entities, including sections for grouping consumables by location within the lot.

# File Description Inventory
- **src/App.tsx**: Main application component that sets up routing, including navigation to the sub-entities page.
- **src/pages/Index.tsx**: Home page component displaying lots with updated information and links to their respective sub-entities.
- **src/pages/SubEntities.tsx**: Updated component for displaying sub-entities of a selected lot, now includes a dropdown for selecting Lot B variants, new buttons for inventory verification, and the detailed inventory structure.
- **src/pages/Inventory.tsx**: Component for managing inventory of a selected sub-entity, including sections for grouping consumables by location.
- **src/data/lots.ts**: Data structure defining lots, their associated sub-entities, and consumable sections, reflecting recent updates in organization and variant support.

# Usage
1. Install dependencies:
   ```
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the linter to check for issues:
   ```
   pnpm run lint
   ```
