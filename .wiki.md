# Project Summary
This project is an advanced inventory management system aimed at enhancing operational efficiency and improving user experience for businesses. It provides collaborative tools that allow multiple users to conduct inventory checks simultaneously. The system includes user authentication, a robust PostgreSQL database, and AI integration for comprehensive inventory oversight. Recent updates have focused on improving data integrity, user experience, and centralized reporting for discrepancies, streamlining inventory management further. Enhancements include improved error handling, user-friendly messaging for errors, and better log grouping for inventory entries.

# Project Module Description
The project consists of various functional modules, including:
- **Authentication:** User registration, login, and session management.
- **Database Management:** PostgreSQL integration for CRUD operations and table management.
- **File Storage:** Object storage for managing images, videos, and documents.
- **Edge Functions:** Custom server-side APIs built with FastAPI.
- **AI Capabilities:** Features for text, image, and audio generation, as well as PDF analysis and voice transcription.
- **Collaborative Inventory Management:** Facilitates multiple users in managing inventory checks on the same lot, including session creation, validation, and abandonment.
- **Discrepancy Reporting:** Manages reports of discrepancies in inventory, ensuring the latest report is retained for each lot and variant, now including detailed reporting with lot variant names and DPS (Data Processing System) names.
- **Error Handling:** Enhanced error boundaries and a catch-all route for improved user experience during errors.
- **Log Grouping Enhancements:** Updates to the log page to ensure proper grouping of entries, prioritizing Lot B and correctly categorizing Cellule entries.

# Usage
1. **Install Dependencies:**
   - For backend: Run `pip install -r app/backend/requirements.txt`
   - For frontend: Run `pnpm install` in the `app/frontend/` directory.
   
2. **Build the Project:**
   - For the frontend: Run `pnpm run build` in the `app/frontend/` directory.

3. **Run the Application:**
   - Start the backend server using `uvicorn app.backend.main:app --reload`
   - Start the frontend development server using `pnpm start` in the `app/frontend/` directory.
