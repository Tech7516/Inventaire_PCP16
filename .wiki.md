# Project Summary
Système de gestion d’inventaire avancé pour entreprises, permettant des contrôles collaboratifs sur un même lot avec authentification, persistance PostgreSQL et parcours d’interface orientés réduction des erreurs. L’application supporte des rapports de divergences et améliore l’expérience utilisateur (gestion d’erreurs et navigation), avec une optimisation récente de l’affichage “Inventaire” pour un usage mobile.

# Project Module Description
- **Gestion d’authentification** : inscription, connexion et gestion de session.
- **Inventaire & collaboration** : création/validation/abandon de sessions de contrôle par lot, et coordination multi-utilisateurs.
- **Rapports de divergences** : conservation du dernier état par lot/variant, affichage enrichi des noms (lot/variant) et DPS.
- **Gestion des erreurs** : limites d’erreurs côté UI + route catch-all pour éviter les écrans cassés.
- **Logs** : regroupement corrigé pour la priorisation Lot B et la catégorisation des entrées (ex. Cellule).
- **Stockage de fichiers** : gestion d’assets (images/vidéos/documents).
- **API (FastAPI) & données** : services backend, modèles/schemas et accès PostgreSQL.
- **IA (selon capacité du projet)** : génération (texte/image/audio) et analyse (PDF/transcription vocale).

# Directory Tree
app/
- **backend/** : API FastAPI (main, routers, services, modèles, schemas, handlers)
- **frontend/** : application React/TypeScript (pages, composants, libs d’accès API)
- **uploads/** : stockage local pour fichiers téléversés
- **(scripts)** : démarrage/packaging via scripts de lancement côté app

# File Description Inventory
- **app/backend/main.py** : points d’entrée backend, définitions/chargements exécutés au démarrage
- **app/backend/requirements.default** : liste de dépendances par défaut pour le backend
- **app/backend/requirements.txt** : dépendances backend verrouillées
- **app/start_app_v2.sh** : script de lancement pour démarrer l’environnement d’application
- **app/frontend/src/pages/Inventory.tsx** : optimisation de l’interface Inventaire pour mobile (suppression de troncature, mise en page sur 2 lignes)
  
# Technology Stack
- **Backend** : FastAPI, PostgreSQL
- **Frontend** : React, TypeScript, Tailwind CSS
- **Déploiement** : Atoms Cloud

# Usage
1. Backend : installer les dépendances via `pip install -r app/backend/requirements.txt`
2. Frontend : installer via `pnpm install` dans `app/frontend/`
3. Construire le frontend : exécuter `pnpm run build` dans `app/frontend/`
4. Lancer l’application :
   - Backend : `uvicorn app.backend.main:app --reload`
   - Frontend : `pnpm start` dans `app/frontend/`
